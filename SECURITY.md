## ⚠️ Anti-Impersonation & Malware Warning

1. **No External Binary Loaders:**  
   We **NEVER** distribute pre-compiled binary loaders, external `.exe` setup wizards, or password-protected archives (`.zip`/`.rar`) on third-party file-sharing sites (MediaFire, Mega, etc.). Any external download claiming to be an "All-in-one loader" or "Pre-compiled Jaina release" is an **Infostealer Trojan** designed to steal your Discord tokens, browser credentials, and crypto wallets.

2. **Official Maintainer:**  
   The **ONLY** authorized developer and maintainer is **[DarckRovert](https://github.com/DarckRovert)**. Any repository created by random burner accounts (e.g. `Gel88566ight`, `Aursolstice160913-alt`, `Killm12321idgard`) claiming to be JainaCore modules is a malicious clone.

3. **Verify Commit Authenticity:**  
   Always verify that commits originate from `github.com/DarckRovert`.

## 🔒 Reporting a Vulnerability or Malicious Clone

If you discover a security vulnerability in our codebase, or find a malicious clone/phishing repository impersonating Project Jaina:

- **Direct Email:** Contact the lead architect at `darckrovert@gmail.com`.
- **Discord:** Join our community Discord and message staff privately.
- **GitHub Abuse:** Report fraudulent repositories immediately to GitHub Trust & Safety under the `Malware or exploits` category.

We respond to security and impersonation reports within 24 hours.
